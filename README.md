# Code Club Website

A five-page website for the student Code Club at upGrad School of Technology.
Built with plain HTML and CSS, using Git branches and pull requests, and hosted on GitHub Pages.

## Live site

https://bishaldas5112007-lang.github.io/sot-code-club/

![Code Club home page](images/screenshot.png)

## Pages

| Page | File | What's on it |
|---|---|---|
| Home | index.html | Hero, dashboard, ticker, feature cards, about section, event banner |
| Events | events.html | Three event cards, past events list |
| Team | team.html | Four member cards, join box |
| Gallery | gallery.html | Six image cards with captions |
| Contact | contact.html | Form, info card, FAQ |

## Built with

- HTML5 (semantic tags: header, nav, main, section, article, footer)
- CSS3 (flexbox, one shared `styles.css`, hover effects, mobile layout)
- Git and GitHub (branches, pull requests, a resolved merge conflict, a revert, a release tag)
- GitHub Pages for hosting

## Folder structure

    sot-code-club/
    index.html  events.html  team.html  gallery.html  contact.html
    styles.css
    README.md  .gitignore
    images/

## Run it locally

1. Clone the repo: `git clone git@github.com:bishaldas5112007-lang/sot-code-club.git`
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
